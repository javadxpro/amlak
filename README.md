# 🏠 املاک جواد حامدی — وب‌سایت ملک‌های شوش دانیال

سایت با **HTML + CSS + JavaScript** نوشته شده (بدون هیچ فریمورک و پکیج خارجی).
مشخصات و ملک‌ها از `properties.json` خوانده می‌شود: جستجو، فیلتر متراژ، قیمت،
داخل کوچه / برِ خیابان، تعداد خواب و مرتب‌سازی — همه سمت مرورگر و بدون سرور.

## 📁 فایل‌های پروژه

| فایل | کاربرد |
|---|---|
| `index.html` | کل سایت (HTML + CSS + JavaScript در یک فایل) |
| `properties.json` | **لیست ملک‌ها — فقط همین را برای تغییر املاک ویرایش کنید** |
| `.nojekyll` | لازم است سر جایش بماند (تا گیت‌هاب سایت را دستکاری نکند) |
| `server.js` | سرور محلی برای تست روی کامپیوتر (اختیاری) |
| `package.json` | مشخصات پروژه Node — **هیچ پکیجی برای نصب ندارد** |
| `راهنما.md` | توضیح کامل فرمت ملک‌ها در JSON |

## 🌐 انتشار رایگان روی گیت‌هاب Pages

1. فایل‌های `index.html`، `properties.json` و `.nojekyll` را در ریپازیتوری بگذارید
   (از **Add file ← Upload files** بالای لیست فایل‌ها)
2. **Settings ← Pages** ← Source: شاخه `main` و پوشه `/ (root)` ← Save
3. آدرس سایت: `https://USERNAME.github.io/REPO-NAME/`

⚠️ **نکته مهم:** کد سایت باید داخل فایل `index.html` باشد، نه فایل `.md`!
فایل‌های Markdown (مثل همین README) فقط برای متن توضیحات هستند و اسکریپت و فیلترهای
داخل آن‌ها توسط گیت‌هاب اجرا نمی‌شوند — همین باعث می‌شد فیلترها «بعضی وقتا کار نکنند».

## 💻 اجرای محلی (اختیاری — برای تست قبل از آپلود)

باید [Node.js](https://nodejs.org) نصب باشد. بعد در پوشه پروژه:

```bash
npm install   # چیزی نصب نمی‌کند! پروژه هیچ پکیجی لازم ندارد
npm start     # یا: node server.js
```

سپس مرورگر: `http://localhost:3000`

## 🔁 آپدیت ملک‌ها

1. `properties.json` را ویرایش کنید (فرمت در `راهنما.md`)
2. هر دو فایل `index.html` و `properties.json` را دوباره در گیت‌هاب آپلود کنید (Commit changes)
3. ۱ تا ۲ دقیقه صبر و سپس سایت را با **Ctrl+Shift+R** باز کنید
