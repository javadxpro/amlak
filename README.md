# 🏠 املاک جواد حامدی — وب‌سایت ملک‌های شوش دانیال

سایت تک‌صفحه‌ای **فارسی و راست‌چین** برای مشاور املاک جواد حامدی (شوش، محله دانیال‌نبی و اطراف).
با **HTML + CSS + JavaScript خالص** نوشته شده — بدون فریمورک، بدون CDN، بدون فونت یا کتابخانه خارجی —
و همه‌چیز داخل یک فایل `index.html` است. لیست ملک‌ها از `properties.json` خوانده می‌شود و
جستجو، فیلتر متراژ/قیمت/خواب، «داخل کوچه / برِ خیابان اصلی» و مرتب‌سازی همه در مرورگر انجام می‌شود.

🌐 **آدرس سایت:** https://javadxpro.github.io/amlak/

## 📁 فایل‌های پروژه

| فایل | کاربرد |
|---|---|
| `index.html` | کل سایت (HTML + CSS + JavaScript در یک فایل) — لوگو و آیکون‌ها همگی SVG داخل همین فایل هستند |
| `properties.json` | **لیست ملک‌ها — برای تغییر املاک فقط همین فایل را ویرایش کنید** |
| `.nojekyll` | فایل خالی — لازم است سر جایش بماند تا گیت‌هاب سایت را پردازش نکند |
| `README.md` | همین راهنما |
| `راهنما.md` | توضیح کامل فرمت هر ملک در JSON |
| `server.js` و `package.json` | اختیاری — سرور محلی برای تست روی کامپیوتر (Node.js، بدون هیچ پکیجی) |
| `sync.py` | اختیاری — نسخه‌ی پشتیبان داده‌ها را داخل `index.html` تازه می‌کند |

## 🖼️ قانون تصاویر

در این پروژه **هیچ فایل عکس (jpg / png / webp) وجود ندارد و نباید اضافه شود.**
لوگوی سایت، فاویکون و همه‌ی آیکون‌ها به‌صورت SVG داخل `index.html` ساخته شده‌اند؛
در `properties.json` مقدار `"image": "logo"` یعنی کارت ملک با لوگوی سایت نمایش داده شود.

## 🔁 آپدیت ملک‌ها (مرحله به مرحله)

1. در گیت‌هاب فایل `properties.json` را باز کنید و روی آیکون مداد (Edit) بزنید — یا فایل ویرایش‌شده را با **Add file ← Upload files** جایگزین کنید.
2. ملک را اضافه/ویرایش کنید (فرمت دقیق در `راهنما.md`). هر ملک باید `id` یکتا داشته باشد.
3. پایین صفحه **Commit changes** را بزنید.
4. یک تا دو دقیقه صبر کنید تا گیت‌هاب سایت را دوباره بسازد (پیشرفت در تب **Actions**).
5. سایت را باز کنید و با **Ctrl+Shift+R** تازه‌سازی کنید تا نسخه‌ی کش‌شده‌ی قبلی نیاید.

سایت همیشه `properties.json` را با دور زدن کش می‌خواند، پس تغییرات بلافاصله دیده می‌شود.
یک نسخه‌ی پشتیبان از داده‌ها داخل `index.html` هم هست که فقط وقتی `properties.json` در دسترس نباشد
استفاده می‌شود؛ اگر خواستید آن هم به‌روز شود، روی کامپیوتر دستور `python3 sync.py` را اجرا کنید و
`index.html` را هم آپلود کنید (اختیاری).

## ⚠️ اگر پیام رنگی بالای لیست دیدید

- **پیام قرمز «داده‌ها قابل خواندن نیست — JSON خراب است»:** موقع ویرایش، یک کاما یا گیومه کم/زیاد شده.
  آخرین تغییر `properties.json` را بررسی کنید؛ تا رفع مشکل، سایت داده‌های پشتیبان را نشان می‌دهد و از کار نمی‌افتد.
- **پیام زرد «نسخه آفلاین»:** فایل مستقیماً از روی کامپیوتر باز شده (آدرس با `file:` شروع می‌شود).
  در این حالت مرورگر اجازه‌ی خواندن `properties.json` را نمی‌دهد و داده‌های پشتیبان نمایش داده می‌شود؛ روی گیت‌هاب این پیام نمی‌آید.

## 🌐 تنظیمات GitHub Pages

سایت از شاخه‌ی `main` و پوشه‌ی ریشه منتشر می‌شود:
**Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← / (root) ← Save**.
هر Commit روی `main` بعد از یک تا دو دقیقه روی سایت اعمال می‌شود.

## 💻 اجرای محلی (اختیاری)

اگر Node.js نصب دارید، در پوشه‌ی پروژه دستور `npm start` (یا `node server.js`) را اجرا کنید و
در مرورگر آدرس `http://localhost:3000` را باز کنید. هیچ پکیجی نصب نمی‌شود.
